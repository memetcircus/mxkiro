## Recording Tips

1. **Camera angles:**
   - Close-up of MX Console LCD (macro lens or zoom)
   - Over-shoulder showing both console and monitor
   - Screen recording of Kiro IDE

2. **Lighting:**
   - LCD buttons look best in dim ambient light
   - Ghost animation pops in slight darkness

3. **Audio:**
   - Voiceover recorded separately (clean mic)
   - Subtle background music (lo-fi or ambient)
   - Button click sounds are satisfying — keep them audible

4. **Editing:**
   - Speed up wait times (ghost walking, Kiro thinking)
   - Add text overlays for feature names
   - Zoom into LCD for animation details
   - Picture-in-picture: screen + console simultaneously

5. **Thumbnail (YouTube):**
   - MX Console with ghost animation visible
   - "AI Coding Companion" text
   - Kiro ghost icon prominent
   - Purple/dark color scheme
