## MX Console Prompt Skill

When invoked, this skill sends the provided argument as a prompt to Kiro.
Used internally by the MX Creative Console plugin to route button presses.

If called with arguments, the argument text is sent directly as a prompt.
If called without arguments, show the current button configuration.

## Usage

```
/mx-prompt Dürüst ol, bu kodu eleştir
/mx-prompt Review this PR for security issues
```
