## MX Console Session Skill

Manages how sessions appear on the MX Creative Console.

## Commands

- `/mx-session list` — Show all available sessions
- `/mx-session health` — Check current session health (token count)
- `/mx-session compact` — Compact current session to free context
- `/mx-session new` — Start a fresh session
